## 🛠️ How to Run

**Using Turbo C:**
1. Open Turbo C IDE
2. Load the `.c` file
3. Press `Alt + F9` to compile
4. Press `Ctrl + F9` to run

**Using GCC (Linux/Mac/Windows):**
```bash
gcc filename.c -o output
./output
```
